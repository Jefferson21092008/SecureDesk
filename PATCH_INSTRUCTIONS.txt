SecureDesk V0.5.3 — Métricas por departamento, categoria e agente

Base esperada: V0.5.2 já mergeada na main.

1. Atualize a main e crie a branch:
   git checkout main
   git pull origin main
   git checkout -b feat/metrics-breakdown

2. Extraia este patch na raiz do SecureDesk, substituindo os arquivos.

3. Recrie os containers:
   docker compose down
   docker compose up --build -d

4. Confirme o Alembic:
   docker compose exec api alembic current

   Esperado:
   0012_add_security_audit_logs (head)

5. Rode os testes e lint:
   docker compose exec api pytest -q
   docker compose exec api ruff check .

6. Se tudo passar:
   git add .
   git commit -m "feat: add ticket metrics breakdown"
   git push -u origin feat/metrics-breakdown

Novidade principal:
- GET /metrics/breakdown
- agrupamento por departamento
- agrupamento por categoria
- agrupamento por agente responsável
- buckets null para tickets sem classificação/atribuição
- escopo OWN para USER e GLOBAL para AGENT/ADMIN
- agregações realizadas diretamente no banco

Não há migration nova nesta etapa.
