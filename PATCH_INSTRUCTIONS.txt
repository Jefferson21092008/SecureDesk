SecureDesk V1.0.4 — integração frontend/backend

Base esperada: V1.0.3 já mergeada na main.

Principais mudanças:
- adiciona GET /auth/me para identidade e papel do usuário autenticado;
- frontend passa a autenticar na API real com JWT;
- token fica no sessionStorage e logout revoga a sessão no backend;
- Nginx encaminha /api/* para o serviço FastAPI no Docker Compose;
- tickets, métricas, departamentos e auditoria passam a usar dados reais;
- criação de chamados passa a persistir no PostgreSQL;
- respostas 401, 403 e 429 recebem tratamento no frontend;
- valores vindos da API são escapados antes de entrar em HTML dinâmico;
- adiciona scripts/seed_demo.py para popular ambiente local de demonstração;
- sem migration nova; o head continua 0012_add_security_audit_logs.

Fluxo sugerido:
1. git checkout main
2. git pull origin main
3. git checkout -b feat/frontend-api-integration
4. extraia este patch na raiz do projeto, substituindo os arquivos
5. docker compose down
6. docker compose up --build -d
7. docker compose exec api alembic current
8. docker compose exec api pytest -q
9. docker compose exec api ruff check .
10. opcional: docker compose exec api python scripts/seed_demo.py
11. abra http://localhost:3000

Resultado esperado dos testes desta versão: 209 passed.
