SecureDesk V0.5.4 — Filtros por período e revisão final de métricas

Base esperada: V0.5.3 já mergeada na main.

1. Atualize a main e crie a branch:
   git checkout main
   git pull origin main
   git checkout -b feat/metrics-period

2. Extraia este patch na raiz do SecureDesk, substituindo os arquivos.

3. Recrie os containers:
   docker compose down
   docker compose up --build -d

4. Confirme o Alembic:
   docker compose exec api alembic current

   Esperado:
   0012_add_security_audit_logs (head)

5. Rode os testes e lint:
   docker compose exec api pytest -q
   docker compose exec api ruff check .

6. Se tudo passar:
   git add .
   git commit -m "feat: add metrics period filters"
   git push -u origin feat/metrics-period

Novidades principais:
- date_from/date_to em /metrics/overview
- date_from/date_to em /metrics/sla
- date_from/date_to em /metrics/breakdown
- datas inclusivas no recorte UTC de Ticket.created_at
- suporte a períodos abertos usando apenas um dos parâmetros
- 422 quando date_from é posterior a date_to
- filtros de período combinados com OWN/GLOBAL
- revisão final do módulo de métricas
- versão da aplicação/pacote atualizada para 0.5.0

Não há migration nova nesta etapa.
