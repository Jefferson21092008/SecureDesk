SecureDesk V0.3.3 - Ticket attachments

1. Apply this patch over the project root while on branch:
   feat/ticket-attachments

2. Rebuild and start Docker:
   docker compose down
   docker compose up --build -d

3. Confirm the migration:
   docker compose exec api alembic current

   Expected:
   0008_add_ticket_attachments (head)

4. Run tests and lint:
   docker compose exec api pytest -q
   docker compose exec api ruff check .

5. If everything is green:
   git add .
   git commit -m "feat: add ticket attachments"
   git push -u origin feat/ticket-attachments

Notes:
- Docker stores uploaded files in the named volume securedesk_attachments.
- Do not use `docker compose down -v` unless you intentionally want to erase both PostgreSQL data and uploaded attachments.
- Allowed baseline types: PDF, PNG, JPEG and plain text/log files.
- Default size limit: 5 MiB, configurable with ATTACHMENT_MAX_BYTES.
