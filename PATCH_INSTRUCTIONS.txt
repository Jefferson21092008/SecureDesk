SecureDesk V0.5.2 — Métricas de SLA

Base esperada: V0.5.1 já mergeada na main.

1. Atualize a main e crie a branch:
   git checkout main
   git pull origin main
   git checkout -b feat/metrics-sla

2. Extraia este patch na raiz do SecureDesk, substituindo os arquivos.

3. Recrie os containers:
   docker compose down
   docker compose up --build -d

4. Confirme o Alembic:
   docker compose exec api alembic current

   Esperado:
   0012_add_security_audit_logs (head)

5. Rode os testes e lint:
   docker compose exec api pytest -q
   docker compose exec api ruff check .

6. Se tudo passar:
   git add .
   git commit -m "feat: add SLA metrics"
   git push -u origin feat/metrics-sla

Novidade principal:
- GET /metrics/sla
- contagem ON_TRACK / MET / BREACHED
- taxa de cumprimento entre tickets fechados
- tempo médio de resolução dos tickets fechados
- escopo OWN para USER e GLOBAL para AGENT/ADMIN

Não há migration nova nesta etapa.
