SecureDesk V1.0.6 — polimento final e release v1.0.0

Base esperada:
- V1.0.5 já mergeada na main
- deploy Render + Neon funcionando
- Alembic em 0012_add_security_audit_logs

O patch:
- atualiza a versão do pacote/API para 1.0.0;
- adiciona links do ambiente público ao README;
- conclui o roadmap V1.0;
- adiciona CHANGELOG.md;
- adiciona scripts/smoke_test.py para verificação pós-deploy;
- corrige o texto "Ambiente local" no frontend;
- impede que credenciais inválidas do bootstrap apareçam em traceback;
- atualiza documentação de deploy e histórico;
- adiciona testes de regressão da release.

Não há migration nova.

Fluxo sugerido:

1. Atualize a main e crie a branch:
   git checkout main
   git pull origin main
   git checkout -b release/v1.0.0

2. Extraia este patch na raiz do repositório, substituindo os arquivos.

3. Rebuild e validação local:
   docker compose down
   docker compose up --build -d
   docker compose exec api alembic current
   docker compose exec api pytest -q
   docker compose exec api ruff check .

4. Valide o ambiente publicado após o deploy:
   python scripts/smoke_test.py https://securedesk-e2pb.onrender.com

5. Commit e push:
   git add .
   git commit -m "release: prepare SecureDesk v1.0.0"
   git push -u origin release/v1.0.0

Após CI verde e merge, atualize main e crie a tag:
   git checkout main
   git pull origin main
   git tag -a v1.0.0 -m "SecureDesk v1.0.0"
   git push origin v1.0.0
