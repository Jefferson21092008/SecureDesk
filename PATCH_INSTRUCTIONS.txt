SecureDesk V0.4.4 — Audit log de segurança
==========================================

Este patch deve ser aplicado sobre a V0.4.3 concluída.
Esta etapa cria a migration 0012_add_security_audit_logs.

1. Confirme que a main está atualizada e crie a branch:
   git checkout main
   git pull origin main
   git checkout -b security/audit-log

2. Extraia o conteúdo deste ZIP na raiz do SecureDesk, substituindo os arquivos existentes.

3. Recrie os containers sem remover volumes:
   docker compose down
   docker compose up --build -d

4. Confirme a migration:
   docker compose exec api alembic current

   Esperado:
   0012_add_security_audit_logs (head)

5. Rode os testes:
   docker compose exec api pytest -q

   Esperado nesta versão:
   140 passed

6. Rode o lint:
   docker compose exec api ruff check .

   Esperado:
   All checks passed!

7. Se tudo estiver verde:
   git add .
   git commit -m "security: add security audit logging"
   git push -u origin security/audit-log

Principais controles adicionados:
- tabela append-only pela API para eventos de segurança;
- auditoria de criação de conta, login com sucesso/falha e logout;
- auditoria de rate limit global e dos endpoints de autenticação;
- registro de respostas 401/403 fora do login;
- actor_id quando existe usuário autenticado;
- IP, User-Agent, método, caminho, status e detalhes mínimos do evento;
- senha e JWT Bearer bruto nunca são gravados no audit log;
- GET /security/audit somente para ADMIN;
- filtros por event_type, actor_id e status_code, com paginação;
- logs de segurança permanecem separados do histórico funcional dos chamados.
