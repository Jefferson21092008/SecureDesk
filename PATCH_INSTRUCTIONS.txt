SecureDesk V0.3.5 — Departamentos
=================================

Este patch deve ser aplicado sobre a V0.3.4 já concluída (head 0009_add_ticket_sla).

1. Crie a branch:
   git checkout -b feat/ticket-departments

2. Extraia o conteúdo deste ZIP na raiz do SecureDesk, substituindo os arquivos existentes.

3. Recrie os containers sem remover volumes:
   docker compose down
   docker compose up --build -d

4. Confirme a migration:
   docker compose exec api alembic current

   Esperado:
   0010_add_ticket_departments (head)

5. Rode os testes:
   docker compose exec api pytest -q

   Esperado nesta versão:
   91 passed

6. Rode o lint:
   docker compose exec api ruff check .

   Esperado:
   All checks passed!

7. Se tudo estiver verde:
   git add .
   git commit -m "feat: add ticket departments"
   git push -u origin feat/ticket-departments

Principais regras:
- somente ADMIN gerencia a lista de departamentos;
- qualquer usuário autenticado pode consultar departamentos;
- USER escolhe departamento na criação, mas não pode redirecionar o chamado depois;
- AGENT e ADMIN podem alterar/remover department_id;
- GET /tickets aceita department_id como filtro;
- mudanças entram no histórico;
- departamento em uso não pode ser excluído.
