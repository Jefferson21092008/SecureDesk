SecureDesk V1.0.3 — Frontend shell

1. Crie a branch:
   git checkout main
   git pull origin main
   git checkout -b feat/frontend-shell

2. Extraia este patch na raiz do repositório, substituindo os arquivos existentes.

3. Reconstrua os serviços:
   docker compose down
   docker compose up --build -d

4. Confirme os três serviços:
   docker compose ps

   Esperado: db, api e frontend em execução/healthy.

5. Abra o frontend:
   http://localhost:3000/

   Nesta etapa ele usa dados de demonstração. A integração real com a API entra na V1.0.4.

6. Valide o backend e o shell estático:
   docker compose exec api alembic current
   docker compose exec api pytest -q
   docker compose exec api ruff check .

   Esperado:
   0012_add_security_audit_logs (head)
   205 passed
   All checks passed!

7. Commit/push:
   git add .
   git commit -m "feat: add frontend application shell"
   git push -u origin feat/frontend-shell

Observação: não use `docker compose down -v`, pois isso remove os volumes persistentes.
